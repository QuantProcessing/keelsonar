# Wind Signal

Chrome MV3 侧边栏扩展。它复用已登录听风页面的实时 WebSocket，把预警中的交易标的提取出来，并通过 deBot、GMGN 两个轻量入口打开或复用交易页；同时接入方程式新闻（eqn.news）公开快讯，可与听风信号分栏并排或合并为一列；也可以使用自己的 Sub2API Key，在侧栏或独立窗口中向 Grok 调查代币叙事或核实快讯。

## 已登录页面桥接

```text
听风页面（同源登录 Cookie）── 官方 wss://wind.jokkimon.club/ws
          ↓ 仅转发收到的协议帧
扩展 Service Worker ── 解析事件 ── 侧边栏 ── 交易网站
```

- 扩展不申请 `cookies` 权限，不读取、不存储、不复制 Cookie。
- MAIN world 脚本只观察听风页面自己创建的官方 `/ws` 连接，不创建第二条连接。
- 隔离环境把原始协议帧转发到扩展后台；后台验证消息必须来自听风顶层页面后才解析。
- 若没有听风标签页，扩展会打开一个非激活页面作为实时流宿主；已有页面会直接复用。
- 桥接有 5 秒心跳和 MV3 Service Worker 状态恢复，页面断线时仍由听风官方逻辑负责重连。
- 当前只展示事件并导航到交易页，不自动下单、不接触钱包签名。

## 方程式快讯

```text
侧栏 / 分栏窗口打开 ── 后台每秒 GET eqn.news/api/v1/news?limit=20（与官网同一 URL，命中 CDN 1s 缓存）
          ↓ 新编号 → 推送 + 按分组提示音；内容变化 → 修订；扫描窗口内消失 → 撤回
主接口连续失败 3 次 ── 改用官方 MCP（api.eqn.news/public/mcp，3s 一次），每 60s 探测主接口恢复
全部视图关闭 ── 停止请求；重新打开时静默补齐期间的快讯（最多 5 页 × 100 条），不连环响铃
```

- 免费、不需要 Key；`eqn.news` 与 `api.eqn.news` 已写入 `host_permissions`，升级扩展时 Chrome 会请求确认一次新权限。
- 14 个频道归为 6 组：头条（方程式新闻）、公告（币安 / 韩所 / 二三线上新 / Alpha / 理财）、异动（价格 / OI / 大幅波动）、财经（方程式财经 / 美股行情）、动态（CZ & 何一 / Hyperliquid）。设置页可按组关闭显示。
- 快讯没有合约地址，因此不显示 deBot / GMGN；有币种时提供“问 Grok”核实快讯与影响。

## 提示音

四档，两条规则：**响两声 = 值得马上看，响一声 = 有空再看；方波来自听风，钟声来自方程式。**

| 档位 | 包含 | 声音 | 默认 |
|---|---|---|---|
| 听风 · 可交易 | 买卖、喊单、共识、币安上新，及任何带合约地址的信号 | 方波两声上扬 | 开 |
| 听风 · 动态 | 其余推文、回复、关注、观点与资料变更 | 方波一声，音量减半 | 开 |
| 快讯 · 要闻 | 方程式头条、交易所公告与上新 | 钟声 叮—咚 | 开 |
| 快讯 · 其他 | 价格与 OI 异动、财经、动态 | 很轻的一声 | 关 |

- 设置页“提示音”分区可逐档开关并试听；页头铃铛是总开关。
- 1.5 秒内多条消息只响最重要的一档（可交易 > 要闻 > 动态 > 其他），更重要的消息可以打断较轻的。
- 同时打开侧栏和分栏窗口时只有一个视图响铃。
- 从 0.5.0 升级时，原来按快讯分组设置的提示音会自动换算成对应档位。

## 布局

- **分栏**：听风信号与方程式快讯左右并排，各自筛选与滚动。需要至少 720px 宽：把侧栏拖宽，或点页脚“分栏窗口”打开 1180px 宽的独立窗口（再次点击会复用）。
- **合并**：两路消息按时间交织为一列，卡片保持各自样式；上方可选择并入哪些来源，异动默认不并入。
- 侧栏较窄时“分栏”自动退化为“听风信号 / 方程式快讯”单列切换，拖宽后恢复并排。布局选择会保存。

## Grok 叙事调查

1. 在扩展设置的“Grok 叙事调查”中填写 Sub2API 地址、Key 和模型名。地址支持服务根地址、`/v1` 或完整的 `/v1/responses`。
2. 保存时只需授权扩展访问所填写的 Sub2API 域名；Key 保存在 Chrome 扩展的本地可信存储中，不会写入实时流快照。
3. 在有 CA 的预警卡片上点击“问 Grok”。扩展会自动带上链、CA、代币和预警上下文，并启用 X Search 与 Web Search。
4. 在对话顶部点击独立窗口按钮，可以把调查桌单独打开；再次打开时会复用已有窗口。
5. 输入框上方提供“叙事速查”“X 溯源”“风险排查”“热度核验”模板。选择后只会填入输入框，仍可修改或自由输入。
6. 会话会自动保存在 Chrome 本地存储中，侧栏通过历史抽屉查看，独立窗口则常驻显示；最多保留 24 个会话、每个会话 60 条消息。每次请求最多携带最近 10 条消息。

默认模型为 `grok-4.5`，如你的 Sub2API 暴露了其他模型，可直接在设置中替换模型名。

## 本地构建

```powershell
pnpm install
pnpm build
```

打开 `chrome://extensions`，启用“开发者模式”，选择“加载已解压的扩展程序”，加载项目中的 `dist` 目录。

## 测试

1. 在听风网站登录，并确认页面“监控列表”数量正常。
2. 刷新扩展。首次升级到页面桥接版时，扩展会刷新一次现有听风页面，以便在页面脚本之前安装桥接。
3. 打开侧边栏，状态应显示“登录态已确认”。
4. Service Worker 控制台应出现 `页面 WebSocket 握手完成 { mode: 'user', watchCount: ... }`。
5. 新事件到达时会先打印 `页面 WS ↓ 收到原始消息`，随后打印“事件已解析并送入侧边栏”，卡片同步出现。
6. 打开侧栏后，Service Worker 控制台应出现 `方程式快讯补漏完成`；新快讯到达时打印 `方程式新快讯` 与 `方程式快讯送入侧栏`。关闭所有侧栏和分栏窗口后，Network 面板中不应再有 `eqn.news` 请求。

设置页可分别修改 deBot 与 GMGN 的 URL 模板，支持 `{chain}`、`{address}`、`{symbol}` 占位符；外观支持跟随系统、浅色和深色三种模式，页头也可一键切换明暗主题。
